# Recursos visuales institucionales

Copia en esta carpeta los recursos exportados o reutilizados del proyecto de Medidas de Protección 2.0:

```text
public/assets/images/
├── gobmx-logo.png
├── footer-textura.png
└── login-illustration.jpg
```

## Uso

- `gobmx-logo.png`: logotipo del header y footer institucional.
- `footer-textura.png`: se conserva disponible para otras vistas, aunque el frame actual de login no la muestra.
- `login-illustration.jpg`: imagen principal del panel izquierdo del login. Debe exportarse desde Figma sin textos, sombras ni overlays; el oscurecimiento se aplica desde CSS.

La imagen de login debe tener preferentemente una resolución mínima de 1600 × 1600 px y formato JPG optimizado.
